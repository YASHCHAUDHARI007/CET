# **App Name**: CET Prep

## Core Features:

- User Authentication: Enable users to log in securely using their Google accounts or email addresses.
- Test Configuration: Allow users to select subjects (Physics, Chemistry, Mathematics, Biology), chapters, difficulty mix, number of questions, and time limit for their test.
- Dynamic Question Generation: Use an LLM as a tool to dynamically generate MHT CET-style multiple-choice questions based on user-selected subjects, chapters, and difficulty mix.  Each question will have four options, with one correct answer and a detailed explanation.
- Quiz Interface: Display a timed quiz interface with multiple-choice questions.
- Instant Results Calculation: Instantly calculate and display test results, including total score, chapter-wise performance, and time per question.
- Test History: Allow users to view and track their past test results and performance metrics.
- Timer Display: Show a timer to display the remaining time

## Style Guidelines:

- Primary color: Saturated blue (#4285F4), reflecting intelligence, focus, and trust.  Blue is a classic color choice for education apps.
- Background color: Light desaturated blue (#E8F0FE), to provide a clean and calming backdrop that keeps the focus on the content.
- Accent color: Vivid green (#34A853), to indicate correctness, positive progress, and successful completion.
- Body and headline font: 'Inter', a grotesque-style sans-serif font, gives a modern, machined, objective, neutral look that suits both headlines and body text. The app features only short segments of text (no blocks of multiple paragraphs).
- Use clear and intuitive icons for navigation and quiz controls.
- Design a clean and responsive layout that works well on both desktop and mobile devices.
- Incorporate subtle animations to provide feedback and enhance the user experience (e.g., correct/incorrect answer feedback).
